% Question 1: Counting Inversions
\begin{frame}[fragile]
\frametitle{Question 1: Counting Inversions}

Given an (1-indexed) array $A$ of $n$ distinct integers, give an algorithm to count the number of inversions in $O(n \log n)$ time.

\vspace{0.5cm}

An inversion is a pair of $i,j$ such that:
\begin{itemize}
\item $1 \le i < j \le n$
\item $A[i] > A[j]$
\end{itemize}

\vspace{0.5cm}

\textbf{Hint:} Consider a function 
\begin{verbatim}
def inversions(A: list[int]) -> 
              tuple[int, list[int]]
\end{verbatim}
where we are returning both the number of inversions and sorted list $A$.

% Question 4: Max Weight Subarray
\begin{frame}
\frametitle{Question 4: Max Weight Subarray}

Let $A$ be an array of $n$ integers ($A$ is not necessarily sorted). Each integer in $A$ may be positive or negative.

Given $i, j$ satisfying $1 \le i \le j \le n$, define sub-array $A[i:j]$ as the sequence $(A[i], A[i+1], \ldots, A[j])$, and the weight as $A[i] + A[i+1] + \cdots + A[j]$.

\vspace{0.3cm}

\textbf{Example:} $A = (13, -3, -25, 20, -3, -16, -23, 18)$; $A[1:4]$ has weight $5$; $A[2:4]$ has weight $-8$.

\vspace{0.3cm}

\textbf{(a)} Find a sub-array with largest weight among all $A[i:j]$ with $j = n$ in $O(n)$ time.

\vspace{0.2cm}

\textbf{(b)} Find a sub-array with largest weight in $O(n \log n)$ time (among all possible sub-arrays).

\end{frame}

\begin{frame}[fragile]
\frametitle{Question 7: DeadShot (DS Algo Mock-Midsem 2026)}

To celebrate the end of midsems, a group of students head to the CLAB to play Deadshot.io. There are $n$ players, and the $i$-th player has a skill score of $A[i]$.

They want to split into two teams. Rules:
\begin{itemize}
\item Team Kabir must have a total skill score $\ge$ Team Piyush
\item The difference between team scores should be as small as possible
\end{itemize}

Write a function \texttt{balanced\_teams(A)} that returns the minimum possible difference between the total skill scores in $O(n 2^{n/2})$ time.

\vspace{0.3cm}

\textbf{Hint:} The intended solution uses $O(2^{n/2})$ space as we need \textit{two} arrays of that length.

\end{frame}
